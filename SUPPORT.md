# Support

Spool is **experimental `1.0.x`**. Support is best-effort from maintainers and
the community.

## Where to ask

| Need | Where |
|------|--------|
| Usage, build, or API questions | [GitHub Discussions](https://github.com/relicloops/spool/discussions) if enabled, otherwise a carefully scoped [issue](https://github.com/relicloops/spool/issues) after checking the docs |
| Bug report | [Bug report](https://github.com/relicloops/spool/issues/new?template=bug.yml) form |
| Feature idea | [Feature request](https://github.com/relicloops/spool/issues/new?template=feature.yml) form |
| Security vulnerability | [SECURITY.md](SECURITY.md) — **private** advisory only |
| Conduct | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Docs

* [README](README.md)
* [Reference](docs/reference/README.md)
* [Example](docs/example/README.md)
* Public header under `include/spool/`

## What we do not offer

* Guaranteed response times
* Support for unreleased or unofficial forks
* Security triage for applications that only *use* Spool (report those upstream
  unless the defect is clearly in this library)
* Support for Valve bugs (report those in the Valve repository)
